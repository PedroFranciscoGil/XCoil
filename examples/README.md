# Examples

| file | what it is |
|---|---|
| `tutorial_01_first_coils.py` … `tutorial_07_outer_optimization.py` | the scripts of the [tutorials](../docs/tutorials/README.md) |
| `xcoil_coils.py` | the `xcoil-coils` command as a script ([docs/cli.md](../docs/cli.md)) |
| `example_api.py` | the steps of `xcoil-coils` from Python |
| `input.LandremanPaul2021_QA` | an example target boundary in VMEC input format (the Landreman–Paul precise QA) |

Run them from any folder: `python examples/tutorial_01_first_coils.py`. They write their output files into the
current folder.
